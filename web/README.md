# Tebaki web

The Tebaki front end: React 19 + Vite + TypeScript, Tailwind v4 with shadcn/radix components, react-leaflet maps.

- `npm install` then `npm run dev` → http://localhost:5173 (expects the engine API on `http://localhost:8000`)
- `VITE_API_URL=<url> npm run build` → production bundle pointing at a deployed engine
- Design system: "Sodium & Ink" — see `src/index.css` tokens
